# ASSASSIN HOTEL — Premium 3D React Website

A high-end, cinematic, production-quality luxury hotel website built with React, Three.js, Framer Motion, and modern web technologies.

## Features

- **Cinematic Loading Screen** — Branded loading experience with animated progress
- **Custom Cursor** — Desktop cursor with hover states (VIEW, EXPLORE, DRAG)
- **3D Interactive Scenes** — React Three Fiber powered 3D room exploration and hero decorations
- **Responsive Navigation** — Transparent navbar with scroll effects and mobile hamburger menu
- **Full-Screen Hero** — Parallax hero with 3D metallic sculpture and text reveal animations
- **Rooms & Suites** — Horizontal scroll gallery with detailed room pages
- **3D Room Experience** — Interactive 3D architectural environment with clickable hotspots
- **Hotel Experiences** — Scroll-triggered image expansion sections
- **Dining** — Restaurant gallery with modal menu system (Breakfast, Lunch, Dinner, Drinks, Desserts)
- **Editorial Gallery** — Masonry layout with full-screen lightbox (keyboard navigation)
- **Booking System** — Functional frontend booking with price calculation and confirmation
- **Contact Form** — Validated form with animated success state
- **Testimonials** — Auto-transitioning slider with manual navigation
- **Location** — Stylized interactive map UI
- **About Timeline** — Animated timeline with scroll-triggered reveals
- **CTA Section** — Parallax background with call-to-action

## Installation

### Requirements

- Node.js 18+
- Bun (recommended) or npm

### Setup

```bash
# Clone the repository
git clone <repository-url>
cd assassin-hotel

# Install dependencies
bun install
# or
npm install
```

### Development

```bash
bun run dev
# or
npm run dev
```

### Production Build

```bash
bun run build
# or
npm run build
```

### Preview Production Build

```bash
bun run preview
# or
npm run preview
```
